# v1.12 部署包更新說明

日期：2026-10-24。適用 Windows 10／11、NVIDIA GPU。這份補充說明與 docs 中的 v1.6 Word／PDF 手冊一起使用。

## 本次已確認的結果

使用者在 RTX 2080 Ti 11 GB、Windows PowerShell 5.1、PyTorch 2.7.1+cu128 上完成安裝，並回報 v2Pro 真實英文語音合成成功。提供的紀錄包含 s1v3.ckpt、s2Gv2Pro.pth、BERT、CNHuBERT 成功載入、文字特徵提取、語意 Token 推理與音訊合成。

這是使用者實機回報，非本工作環境的獨立 GPU 重測。新版 ZIP 整合後的新電腦完整安裝、14 頁批次、最終影片及微調尚未整套實機重跑。

## 新電腦安裝

1. 完整解壓到 D:\VoiceLab，讓 01_Install.cmd 與 scripts 在同一根目錄；路徑使用英文且不含空白。
2. 確認 NVIDIA 驅動。jieba_fast 含 C 擴充，請安裝 Microsoft C++ Build Tools 的 C++ 工作負載、MSVC x64/x86 與 Windows SDK；若已有完整工具鏈不必重裝。
3. 執行 01_Install.cmd，等待 INSTALL CHECKS PASSED。新環境會自動使用已核對有 Windows wheel 的 pyopenjtalk-plus；若已安裝原版 pyopenjtalk，會保留原版，避免混裝。
4. 執行 02_Check_GPU_Models.cmd，再執行 03_Start_WebUI.cmd。主頁通常是 http://127.0.0.1:9874，TTS 推理頁通常是 http://127.0.0.1:9872。
5. 先用 v2Pro、3–10 秒參考錄音、精確逐字稿與一兩句英文測試。RTX 2080 Ti 初次測試批次大小先設 1；能合成後再依實際用量調整。

## 已正常運作的電腦更新

不需要重新安裝或重做 OpenJTalk 修復。先關閉相關程序並備份，只覆蓋根目錄 CMD、整個 scripts、VERSION、說明與文件。保留 .runtime、GPT-SoVITS、tts_local.yaml、texts、reference、slides、slides.csv、output_audio 與 MP4；不要用包內模板覆蓋個人資料。

## 已整合修正

- Miniforge 版本及 SHA-256、Conda launcher 檔案與 metadata 檢查。
- Torch 與 TorchAudio 2.7.1 配對；避免引入無適用 wheel 的 TorchCodec 路線。
- 停用 user site 與繼承的 PYTHONPATH，固定 Gradio／FastAPI／Starlette 等相容版本。
- Conda 與 pip 輸出先合併，再依真實退出碼判定；完整日誌保存在 logs。
- OpenCC 使用同一官方套件 1.4.2 的 wheel，移除強制原始碼建置選項。
- 新環境使用 pyopenjtalk-plus 0.4.1.post10 與隨附辭典，已有原版環境保留原版。Plus 是衍生實作，日文辭典與部分讀音行為不同於原版，不宣稱日文輸出相同。
- 明確安裝 resampy 0.4.3 與 numpy<2.0，doctor 檢查 GPU 重採樣路徑需要的 kaiser_best 濾波器。
- 09_Repair_OpenJTalk.cmd 保留為特定失敗環境的修復入口，正常安裝者不必執行。

## 參考操作

日常合成使用 03。批次影片流程為準備 reference／texts → 04 啟動 API → 06 逐頁生成 → 試聽全部 WAV → 07 合成影片。slides 放逐頁 PNG，不能以 PPTX／PDF 取代。實際總時間以最終 WAV 與 MP4 為準。

若出錯，保留完整 Traceback 或 logs 中最新 conda／pip 日誌，先辨識失敗套件或階段再處理。安裝檢查通過、介面可開啟、可生成語音及影片交付是不同驗收項目。
