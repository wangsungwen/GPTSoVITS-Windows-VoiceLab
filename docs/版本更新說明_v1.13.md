## 14 頁批次與影片操作
1. slides 放 ES0003_Slide_01.png 至 ES0003_Slide_14.png；texts 中講稿需填入實際內容，slides.csv 配對一致。講稿模板不是最終講稿。
2. reference/reference.wav 為 3–10 秒錄音；reference/reference.txt 填入這段錄音的精確逐字稿，使用 UTF-8。不能保留 [REPLACE 提示，也不能填成另一段要合成的內容。
3. 批次入口預設 --prompt-lang en；若使用中文參考，直接呼叫腳本時改成 zh，並保持錄音、逐字稿與語言一致。輸出講稿語言由 slides.csv 的 text_lang 決定。
4. 用以下命令只檢查資料，不生成語音：

```powershell
$root = 'D:\VoiceLab'
& "$root\.runtime\gptsovits\python.exe" -u "$root\scripts\batch_tts.py" --manifest "$root\slides.csv" --reference "$root\reference\reference.wav" --prompt "$root\reference\reference.txt" --prompt-lang en --out "$root\output_audio" --dry-run
```

5. 啟動 04_Start_API.cmd，等候 127.0.0.1:9880 並保持視窗開啟。另開視窗執行 06_Batch_14_Slides.cmd。9872 是網頁推理，不能代替 API。
6. 若出現 HTTP 400，將上面命令移除 --dry-run，查看 FAILED: 後的 API JSON 原因。Conda command failed 只是摘要。
7. output_audio 既有 slide_XX.wav 受到防覆蓋保護；只在確定要重做時，直接腳本明確加 --overwrite。若批次中途失敗而已有部分音檔，可另外建立只含未完成列的 CSV，再以 --manifest 指定；不要刪除已完成檔案。
8. 試聽全部 14 個 WAV，再執行 07_Make_Presentation_Video.cmd。首次輸出 ES0003_Presentation.mp4；之後自動另存新檔。MP4 為 1080p H.264／AAC，圖片與音檔需配對完整。
9. 檢查最終影片的頁序、聲音、總長與結尾後再提交大會。
